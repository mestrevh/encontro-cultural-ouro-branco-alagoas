# Prompt de Execução: Plan 02 - Design System & TDD

Você é o agente encarregado de executar o **Plan 02** definido no `master-plan.md`. Nossa missão agora é implementar e testar o Design System inicial do projeto (Cores, Fontes, Botões Globais) obrigatoriamente utilizando a metodologia TDD (Test-Driven Development).

## 🎯 Objetivos do Plan 02:
1. Criar uma nova branch para a funcionalidade (ex: `feature/design-system`).
2. Configurar os tokens do Design System (Cores, Fontes) no Tailwind e no `global.css`.
3. Criar os testes (Vitest) para o componente de Botão Global (`Button.astro` ou similar).
4. Implementar o Botão Global apenas para fazer os testes passarem (Red-Green-Refactor).

- **`tailwind-styler`**: Para criar as variáveis de tema, aplicar cores não-genéricas (HSL/Premium) e tipografia.
- **`astro-component-builder`**: Para a estrutura limpa e tipada do componente de botão.
