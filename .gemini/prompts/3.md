# Construção das skills e rules

Você criou certamente os `.agents/Rules` e `.agents/Skills`, porém ele não está sendo utilizado no antigravity cli.

## Objetivo

Seu objetivo é construir a estrutura no `.agents` de forma correta:
1. `.agents/Rules/` deve se tornar `.agents/rules/` com melhoramento dos arquivos .md
2. `.agents/Skills/` deve se tornar `.agents/skills/`. Cada Skill tem que ter a seguinte estrtutura `.agents/skills/[nome da skill]/SKILL.md`

## Panorama

* Otimizar: Melhore os arquivos .md
