# Prompt de Execução: Plan 06 - Release e Deploy

Sua missão é fechar o ciclo de desenvolvimento do projeto, de acordo com o `master-plan.md`.

## Objetivos:
1. **Git Flow (Finalização):** Fazer o merge das melhorias de UX na `develop`. Depois, realizar o merge da `develop` diretamente na `main` (branch de produção).
2. **Versionamento:** Criar a tag Git `v1.0.0` para marcar o primeiro lançamento do projeto.
3. **Validação de Build:** Executar o comando de build estático do Astro para garantir que tudo compila corretamente.
4. **Script de Deploy:** Criar um script `deploy.sh` que facilita o envio para a produção (ex: rodar build, testes e push para a main).

## Skills e Regras:
- Use os comandos do Git para tagear a release.
- Garanta que todos os testes (`vitest run`) passam no build.
