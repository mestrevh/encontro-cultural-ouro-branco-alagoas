# Objetivo
> A tarefa central e os comandos diretos do que precisa ser executado (o "core" do prompt).

<objetivo>
Sua tarefa principal é: configurar o `antigravity cli` para executar da melhor forma os prompts que vou enviar para ele.
Para concluir essa tarefa, você deve:
* Estrutura do `.agents/`
* `Skills` que serão utilizados.
* `Rules` que serão utilizados.
* Quantidade de prompts necessário do inicio do projeto até o deploy.
* Planejamento inicial da construção do site com TDD.
</objetivo>

# Modelo

<modelo_saida>
Entregue o resultado final estruturado estritamente no seguinte formato:
* **Formato:** Faça um formato que consiga atualizar o `.agents/`
* **Estrutura:** 
  1. Configuração do `.agents/`
  2. Construção do `.agents/CONTEX.md` (confirme se é esse nome mesmo)
  3. Skills que deve ser adicionado considerando o ciclo de desenvolvimento no git e adicionado em `.agents/Skills/`
  4. Rules que deve ser adicionado considerando o ciclo de desenvolvimento no git e adicionado em `.agents/Rules/`
* **Restrição de Saída:** Não adicione introduções ou conclusões generosas, vá direto ao ponto.
</modelo_saida>
