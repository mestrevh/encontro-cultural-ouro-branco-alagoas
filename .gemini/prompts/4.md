# Prompt de Execução: Plan 01 - Inicialização do Projeto

Você é o agente encarregado de dar o pontapé inicial no projeto, seguindo rigorosamente a estrutura definida no `master-plan.md` (Plan01).

## 🎯 Objetivos do Plan 01:
1. Inicializar o projeto Astro (`create-astro`).
2. Configurar o Vitest para testes (preparando para TDD).
3. Configurar TailwindCSS e a tipografia base.
4. Limpar o repositório base de arquivos desnecessários.
5. Iniciar a branch `develop`.

## 🧠 Skills que você deve incorporar:
Antes de agir, leia e absorva as instruções das seguintes skills localizadas na pasta `.agents/skills/`:
- **`astro-component-builder`**: Para as melhores práticas de arquitetura Astro.
- **`tdd-vitest-runner`**: Para a correta configuração do ambiente de testes Vitest.
- **`tailwind-styler`**: Para garantir a configuração ideal do TailwindCSS.
- **`git-flow-manager`**: Para realizar as operações corretas no Git (iniciar a branch develop).
