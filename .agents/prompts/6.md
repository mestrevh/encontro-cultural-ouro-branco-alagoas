# Prompt de Execução: Plan 03 - Arquitetura Base & Navegação

Você é o agente encarregado de executar o **Plan 03** definido no `master-plan.md`.

## 🎯 Objetivos do Plan 03:
1. **Git Flow:** Fazer o merge da branch atual (`feature/design-system`) para a `develop`.

3. **TDD:** Criar testes (Vitest + Testing Library) focados em acessibilidade (roles) para os componentes estruturais.
4. **Implementação (Mobile-First):** Codificar o Header, Navigation (com menu hambúrguer para mobile), Footer e o Layout Wrapper em Astro.

## 🧠 Skills requeridas (leia a pasta `.agents/skills/`):

- **`tdd-vitest-runner`**: Seguir rigorosamente o fluxo Red-Green-Refactor.
- **`tailwind-styler`**: Usar breakpoints (`sm:`, `md:`, `lg:`) para resolver o desafio do menu responsivo e criar uma navegação com aspecto Premium/Moderno.
